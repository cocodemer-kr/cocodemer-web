SKIN CODE

Zuerst die Haut betrachten,
auch außerhalb des Geschäfts.

Im Geschäft hat COCODEMER die Haut gemessen
und für jede Kundin und jeden Kunden ein Produkt angemischt.

Doch nicht jeder
konnte ein Geschäft besuchen.

Um denselben Ansatz
auch online anzuwenden,

haben wir Skin Code Solution entwickelt.

DIE IDEE

Wir haben zuerst
die Unterschiede bestimmt.

Ein einziges Kriterium reichte nicht aus,
um die Haut eines Menschen zu verstehen.

COCODEMER betrachtete die Haut
entlang von vier Achsen.

01DRY / OILYTrocken / Fettig
02SENSITIVE / RESISTANTEmpfindlich / Widerstandsfähig
03PIGMENTED / NON-PIGMENTEDPigmentiert / Nicht pigmentiert
04WRINKLE / ELASTICITYFalten / Elastizität

Die vier Achsen ergeben zusammen sechzehn Hauttypen.

COCODEMER nannte diese Klassifizierung
COCODEMER Skin Type Indicator (CSTI).

16 HAUTTYPEN

Sechzehn Typen,
jeder eine andere Kombination.

Sechzehn ist die Anzahl der Hauttypen,
nicht die Anzahl der Produkte.

Jeder Typ ist eine Kombination
der vier Achsen.

SO FUNKTIONIERTE ES

Der Typ wurde bestimmt
und dann passend angemischt.

  1. 01ONLINE SKIN TESTHautzustand online geprüft
  2. 02SKIN TYPEEiner von sechzehn Typen bestimmt
  3. 03PRESCRIPTIONRezeptur für diesen Typ angewendet
  4. 04INDIVIDUAL FORMULATIONSerum für die Kundin oder den Kunden angemischt
  5. 05DELIVERYAngemischtes Serum versandt

Bei Skin Code ging es nicht darum, eines
von mehreren vorgefertigten Produkten auszuwählen.

Der Hauttyp wurde bestimmt,
dann wurde das Serum nach dieser Rezeptur
für die Kundin oder den Kunden angemischt.

98,319
MÖGLICHE REZEPTUREN

Hinter Skin Code stand
ein größeres Anmischsystem.

Das Anmischsystem im Geschäft ermöglichte
98.319 mögliche Rezepturen.

Darauf aufbauend ordnete Skin Code die Haut
sechzehn Typen zu und mischte ein Serum
nach der passenden Rezeptur an,
sobald der Online-Test einen Typ ergeben hatte.

REZEPTURBASIS

Auch innerhalb eines Typs
war die Herstellung nicht identisch.

Skin Code arbeitete mit
vier Serumbasen

und variierte die Wirkstoffe
je nach Hauttyp und Rezeptur.
