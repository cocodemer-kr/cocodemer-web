SKIN CODE

Analizar primero la piel,
también fuera de la tienda.

En la tienda, COCODEMER medía la piel
y preparaba un producto para cada cliente.

Sin embargo, no todo el mundo
podía visitar una tienda.

Para aplicar el mismo análisis
también en línea,

creamos Skin Code Solution.

LA IDEA

Primero distinguimos
las diferencias.

Un solo criterio no bastaba
para analizar la piel de una persona.

COCODEMER analizó la piel
según cuatro ejes.

01DRY / OILYSeca / Grasa
02SENSITIVE / RESISTANTSensible / Resistente
03PIGMENTED / NON-PIGMENTEDPigmentada / No pigmentada
04WRINKLE / ELASTICITYArrugas / Elasticidad

Los cuatro ejes se combinan en dieciséis tipos de piel.

COCODEMER denominó esta clasificación
COCODEMER Skin Type Indicator (CSTI).

16 TIPOS DE PIEL

Dieciséis tipos,
cada uno una combinación distinta.

Dieciséis es el número de tipos de piel,
no el número de productos.

Cada tipo es una combinación
de los cuatro ejes.

CÓMO FUNCIONABA

Se identificaba el tipo
y después se preparaba la fórmula correspondiente.

  1. 01ONLINE SKIN TESTEvaluación del estado de la piel en línea
  2. 02SKIN TYPEIdentificación de uno de los dieciséis tipos
  3. 03PRESCRIPTIONAplicación de la fórmula de ese tipo
  4. 04INDIVIDUAL FORMULATIONSérum preparado para el cliente
  5. 05DELIVERYEnvío del sérum preparado

Skin Code no consistía en elegir uno
entre varios productos ya elaborados.

Se identificaba el tipo de piel
y después se preparaba el sérum
según esa fórmula para el cliente.

98,319
FÓRMULAS POSIBLES

Detrás de Skin Code había
un sistema de preparación personalizada más amplio.

El sistema de preparación personalizada en tienda permitía
98.319 fórmulas posibles.

A partir de ahí, Skin Code clasificaba la piel
en dieciséis tipos y preparaba un sérum
según la fórmula correspondiente
una vez que la prueba en línea indicaba un tipo.

BASE DE FORMULACIÓN

Incluso dentro de un mismo tipo,
la elaboración no era idéntica.

Skin Code partía de
cuatro bases de sérum

y variaba los activos
según el tipo de piel y la fórmula.
