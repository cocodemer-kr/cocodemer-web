SKIN CODE

Eerst de huid lezen,
ook buiten de winkel.

In de winkel mat COCODEMER de huid
en stelde voor elke klant een product samen.

Toch kon niet iedereen
een winkel bezoeken.

Om dezelfde huidanalyse
ook online toe te passen,

ontwikkelden we Skin Code Solution.

HET IDEE

brachten we eerst
de verschillen in kaart.

Eén criterium was niet genoeg
om de huid van één persoon te lezen.

COCODEMER bekeek de huid
langs vier assen.

01DRY / OILYDroog / Vet
02SENSITIVE / RESISTANTGevoelig / Resistent
03PIGMENTED / NON-PIGMENTEDGepigmenteerd / Niet-gepigmenteerd
04WRINKLE / ELASTICITYRimpels / Elasticiteit

De vier assen vormen samen zestien huidtypes.

COCODEMER noemde deze indeling
de COCODEMER Skin Type Indicator (CSTI).

16 HUIDTYPES

Zestien types,
elk een andere combinatie.

Zestien is het aantal huidtypes,
niet het aantal producten.

Elk type is een combinatie
van de vier assen.

HOE HET WERKTE

Het type werd vastgesteld
en daarop afgestemd samengesteld.

  1. 01ONLINE SKIN TESTHuidconditie online gecontroleerd
  2. 02SKIN TYPEEen van de zestien types vastgesteld
  3. 03PRESCRIPTIONHet recept voor dat type toegepast
  4. 04INDIVIDUAL FORMULATIONSerum samengesteld voor de klant
  5. 05DELIVERYSamengesteld serum verzonden

Bij Skin Code ging het er niet om er één te kiezen
uit een reeks kant-en-klare producten.

Het huidtype werd vastgesteld,
daarna werd het serum volgens dat recept
voor de klant samengesteld.

98,319
MOGELIJKE RECEPTUREN

Achter Skin Code stond
een groter samenstellingssysteem.

Het samenstellingssysteem in de winkel bood
98.319 mogelijke recepten.

Op basis daarvan deelde Skin Code de huid in
in zestien types en stelde een serum samen
volgens het bijbehorende recept
zodra de online test een type had opgeleverd.
