OUR HERITAGE

우리는 직접
피부를 측정했습니다.

제품을 권하기 전에
먼저 피부를 봤습니다.

매장에 피부 측정기를 두고 얼굴을 촬영해
이마의 붉은기, 코의 유분, 눈밑의 색소 등
200개가 넘는 항목을 확인했습니다.

그 결과를 바탕으로
세럼과 크림을 고객별로 조제했습니다.

맞춤 세럼은 4가지,
맞춤 크림은 3가지 기준을 두고
피부 상태에 따라 조제 방식을 달리했습니다.

실제 제품은
고객마다 따로 만들어졌습니다.

다시 오면,
다시 피부를 봤습니다.

한 달 뒤 다시 방문하면
피부를 다시 측정했습니다.

피부 상태가 달라져 있으면
이전과 같은 제품을 그대로 만들지 않았습니다.

그때의 피부에 맞춰
다시 조제했습니다.

SKIN CODE SOLUTION

매장 밖에서도
같은 기준을 이어갔습니다.

매장에 직접 오지 않아도
자신의 피부를 같은 기준으로 이해할 수 있도록
Skin Code Solution을 만들었습니다.

피부를

  • 건성 / 지성
  • 민감 / 저항
  • 색소 / 비색소
  • 주름 / 탄력

그 조합으로 16가지 피부 타입을 만들었습니다.

COCODEMER Skin Type Indicator(CSTI)라고 이름 붙였습니다.

98,319가지 처방이 가능했습니다.

16가지 피부 타입에 맞는 처방 체계를 만들었습니다.

해당 처방에 따라
세럼을 고객별로 조제해 발송했습니다.
