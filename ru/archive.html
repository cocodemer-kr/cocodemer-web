01 · ИНДИВИДУАЛЬНОЕ СОСТАВЛЕНИЕ

Всё началось
с кожи одного человека.

АРХИВ

Мы не выбирали продукт заранее.

Анализатор кожи в магазине фотографировал лицо и выдавал
более двухсот показателей — покраснение на лбу, жирность на носу,
пигментацию под глазами и многое другое.

Изучив состояние кожи в тот день,
мы составляли сыворотку и крем для этого клиента.

Составление велось по четырём критериям для сыворотки
и трём — для крема
и менялось в зависимости от состояния кожи.

Сам продукт
получался разным для каждого клиента.

При повторном визите через месяц
мы снова измеряли кожу.

Если кожа изменилась,
мы не повторяли прежнюю формулу.

Мы составляли средство заново
для той кожи, которую видели перед собой.

ПРИМЕЧАНИЕ

Четыре критерия для сыворотки и три для крема — это критерии составления, а не количество продуктов.
Услуга индивидуального составления средств для каждого клиента больше не предоставляется.

03 · SKIN CODE

Тот же подход —
за пределами магазина.

Чтобы люди, которые не могли прийти в магазин,
тоже могли изучить свою кожу тем же способом,

мы создали Skin Code Solution.

  • Сухая / Жирная
  • Чувствительная / Устойчивая
  • Пигментированная / Непигментированная
  • Морщины / Упругость

Четыре оси в сочетании дают
шестнадцать типов кожи.

После того как онлайн-тест кожи определял тип,
сыворотку составляли по рецептуре этого типа
и отправляли клиенту.
