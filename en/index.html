COCODEMER HERITAGE

Skin differs from person to person.
Should everyone use the same product?

COCODEMER began with that question.

Before recommending a product we looked at the skin,
and measured its condition in store.

From those readings
we compounded a different serum and cream for each customer.

A month later we read the skin again,
and did not simply repeat the same formula.

The method changed.
Reading the skin first did not.

We no longer run the per-customer compounding service.

What we learned there now shapes how we build products:
we design skincare in three stages.
