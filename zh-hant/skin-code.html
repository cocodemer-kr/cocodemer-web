SKIN CODE

先解讀肌膚，
在門市之外也一樣。

在門市，COCODEMER 測量肌膚，
並為每位顧客調配產品。

然而，並不是每個人
都能親臨門市。

為了在線上
也能採用同樣的解讀方式，

我們打造了 Skin Code Solution。

構想

我們先將差異
區分開來。

要解讀一個人的肌膚，
單一標準並不足夠。

COCODEMER 從
四個指標來觀察肌膚。

01DRY / OILY乾性 / 油性
02SENSITIVE / RESISTANT敏感 / 耐受
03PIGMENTED / NON-PIGMENTED色素 / 非色素
04WRINKLE / ELASTICITY皺紋 / 彈性

四個指標組合出十六種膚質類型。

COCODEMER 將這套分類命名為
COCODEMER Skin Type Indicator（CSTI）。

16 種膚質類型

十六種類型，
各是不同的組合。

十六是膚質類型的數量，
而非產品的數量。

每種類型都是
四個指標的組合。

當時的運作方式

先確認類型，
再依類型調配。

  1. 01ONLINE SKIN TEST線上檢測肌膚狀態
  2. 02SKIN TYPE確認為十六種類型之一
  3. 03PRESCRIPTION套用該類型的配方
  4. 04INDIVIDUAL FORMULATION為顧客調配精華液
  5. 05DELIVERY寄送調配好的精華液

Skin Code 並不是從一組現成產品中
挑選其中一款。

先確認膚質類型，
再依該配方
為顧客調配精華液。

98,319
可調配處方

在 Skin Code 背後，
是一套規模更大的調配系統。

門市的調配系統
可產生 98,319 種配方。

以此為基礎，Skin Code 將肌膚
分為十六種類型，在線上測驗確認類型後，
依相應的配方
調配精華液。

調配基底

即使在同一類型之中，
製作方式也不盡相同。

Skin Code 以
四種精華液基底為基礎，

並依膚質類型與配方
