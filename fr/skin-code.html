SKIN CODE

Analyser la peau d'abord,
hors de la boutique aussi.

En boutique, COCODEMER mesurait la peau
et préparait un produit pour chaque client.

Mais tout le monde
ne pouvait pas se rendre en boutique.

Pour appliquer la même analyse
en ligne également,

nous avons créé Skin Code Solution.

L'IDÉE

Nous avons d'abord distingué
les différences.

Un seul critère ne suffisait pas
pour analyser la peau d'une personne.

COCODEMER a observé la peau
selon quatre axes.

01DRY / OILYSèche / Grasse
02SENSITIVE / RESISTANTSensible / Résistante
03PIGMENTED / NON-PIGMENTEDPigmentée / Non pigmentée
04WRINKLE / ELASTICITYRides / Élasticité

Les quatre axes se combinent en seize types de peau.

COCODEMER a baptisé cette classification
COCODEMER Skin Type Indicator (CSTI).

16 TYPES DE PEAU

Seize types,
chacun une combinaison différente.

Seize est le nombre de types de peau,
et non le nombre de produits.

Chaque type est une combinaison
des quatre axes.

COMMENT IL FONCTIONNAIT

Le type était identifié,
puis la préparation suivait.

  1. 01ONLINE SKIN TESTÉtat de la peau vérifié en ligne
  2. 02SKIN TYPEIdentification de l'un des seize types
  3. 03PRESCRIPTIONApplication de la prescription propre à ce type
  4. 04INDIVIDUAL FORMULATIONSérum préparé pour le client
  5. 05DELIVERYExpédition du sérum préparé

Skin Code ne consistait pas à choisir un produit
parmi une série de produits tout prêts.

Le type de peau était identifié,
puis le sérum était préparé
selon cette prescription pour le client.

98,319
PRESCRIPTIONS POSSIBLES

Derrière Skin Code se trouvait
un système de préparation plus vaste.

Le système de préparation en boutique permettait
98,319 prescriptions possibles.

Sur cette base, Skin Code classait la peau
en seize types et préparait un sérum
selon la prescription correspondante
une fois le type déterminé par le test en ligne.

BASE DE FORMULATION

Même au sein d'un même type,
la préparation n'était pas identique.

Skin Code s'appuyait sur
quatre bases de sérum,

et faisait varier les actifs
selon le type de peau et la prescription.
