01 · オーダーメイド

一人の肌から
始まりました。

アーカイブ

先に製品を選ぶことはしませんでした。

店頭の肌分析機が顔を撮影し、
額の赤み、鼻の皮脂、目の下の色素など、
二百を超える測定結果を示しました。

その日の肌を読み解いたうえで、
そのお客様のためのセラムとクリームを調合しました。

調合は、セラムは四つ、
クリームは三つの基準をもとに行い、
肌の状態に応じて変えていきました。

製品そのものが、
お客様ごとに異なるものになりました。

一か月後の再来店時には、
もう一度肌を測定しました。

肌が変わっていれば、
以前の処方を繰り返すことはしませんでした。

目の前の肌に合わせて、
あらためて調合しました。

注記

セラムの四つ、クリームの三つという数字は調合の基準であり、製品の数ではありません。
お客様ごとのオーダーメイド調合サービスは、現在行っておりません。

03 · SKIN CODE

同じ基準を、
店舗の外へ。

店舗に来られない方も、
同じ方法で自分の肌を読み解けるように、

Skin Code Solutionをつくりました。

  • 乾性 / 脂性
  • 敏感 / 抵抗性
  • 色素性 / 非色素性
  • シワ / ハリ

四つの軸の組み合わせから、
十六の肌タイプが生まれます。

オンラインの肌テストでタイプを判定したあと、
そのタイプの処方に沿ってセラムを調合し、
お客様へ発送しました。
