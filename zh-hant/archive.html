01 · 客製化

一切始於
一個人的肌膚。

過往系列

我們沒有先挑選產品。

門市的肌膚分析儀拍攝臉部後，會回傳
兩百多項測量數據——額頭的泛紅、鼻子的油脂、
眼下的色素等等。

解讀當天的肌膚狀態後，
我們為該位顧客調配精華液與乳霜。

調配依據精華液的四項標準
與乳霜的三項標準進行，
並隨肌膚狀態而調整。

產品本身
因每位顧客而不同。

一個月後回訪時，
我們會再次測量肌膚。

如果肌膚有所改變，
就不會沿用先前的配方。

我們依眼前的肌膚
重新調配。

備註

精華液的四項與乳霜的三項數字是調配標準，並非產品數量。
顧客個別調配服務已不再提供。

03 · SKIN CODE

同樣的解讀方式，
延伸到門市之外。

為了讓無法親臨門市的人，
也能用同樣的方式了解自己的肌膚，

我們打造了 Skin Code Solution。

  • 乾性 / 油性
  • 敏感 / 耐受
  • 色素 / 非色素
  • 皺紋 / 彈性

四個指標組合出
十六種膚質類型。

透過線上肌膚測驗確認類型後，
依該類型的配方調配精華液，
再寄送給顧客。

並區分出它所需要的。
