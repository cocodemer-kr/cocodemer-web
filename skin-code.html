SKIN CODE

매장 밖에서도,
피부를 먼저 보기 위해.

COCODEMER는 매장에서
피부를 측정하고 고객별로 제품을 조제했습니다.

하지만 모든 사람이
매장을 방문할 수 있는 것은 아니었습니다.

같은 맞춤의 기준을
온라인에서도 적용하기 위해

Skin Code Solution을 만들었습니다.

THE IDEA

피부의 차이를
먼저 나눠봤습니다.

한 사람의 피부를 이해하려면
한 가지 기준만으로는 부족했습니다.

COCODEMER는 피부를
네 가지 축으로 나눠 바라봤습니다.

01DRY / OILY건성 / 지성
02SENSITIVE / RESISTANT민감 / 저항
03PIGMENTED / NON-PIGMENTED색소 / 비색소
04WRINKLE / ELASTICITY주름 / 탄력

네 가지 축의 조합으로
16가지 피부 타입을 구분했고,

COCODEMER는 이 피부 분류 체계를
COCODEMER Skin Type Indicator(CSTI)라고 이름 붙였습니다.

16 SKIN TYPES

열여섯 가지 타입,
서로 다른 피부의 조합.

16은 제품의 수가 아니라
피부 타입의 수입니다.

각 타입은
네 가지 피부 축의 조합으로 만들어졌습니다.

이미지를 누르면 크게 볼 수 있습니다

HOW IT WORKED

타입을 확인하고,
그에 맞게 조제했습니다.

  1. 01ONLINE SKIN TEST온라인에서 피부 상태 확인
  2. 02SKIN TYPE16가지 타입 중 해당 타입 확인
  3. 03PRESCRIPTION타입에 맞는 처방 적용
  4. 04INDIVIDUAL FORMULATION고객별 세럼 조제
  5. 05DELIVERY조제한 세럼 발송

Skin Code는 미리 만들어 둔 제품 중
하나를 고르는 것이 아니었습니다.

피부 타입을 확인한 뒤
해당 처방에 따라
세럼을 고객별로 조제했습니다.

98,319
POSSIBLE PRESCRIPTIONS

Skin Code 뒤에는
더 큰 맞춤 조제 체계가 있었습니다.

매장의 맞춤 조제 시스템에서는
98,319가지 처방이 가능했습니다.

Skin Code는 이 경험을 바탕으로
피부를 16가지 타입으로 나누고,
온라인 테스트 결과에 따라
해당 처방으로 세럼을 조제하는 체계를 만들었습니다.
