SKIN CODE

Nejprve číst pleť
i mimo prodejnu.

V prodejně COCODEMER měřil pleť
a pro každého zákazníka míchal přípravek.

Ne každý však
mohl prodejnu navštívit.

Abychom stejné čtení pleti
mohli uplatnit i online,

vytvořili jsme Skin Code Solution.

MYŠLENKA

Nejprve jsme oddělili
rozdíly.

Jedno kritérium nestačilo
k přečtení pleti jednoho člověka.

COCODEMER se díval na pleť
ve čtyřech osách.

01DRY / OILYSuchá / mastná
02SENSITIVE / RESISTANTCitlivá / odolná
03PIGMENTED / NON-PIGMENTEDS pigmentací / bez pigmentace
04WRINKLE / ELASTICITYVrásky / pružnost

Čtyři osy se kombinují do šestnácti typů pleti.

COCODEMER nazval tuto klasifikaci
COCODEMER Skin Type Indicator (CSTI).

nikoli počet produktů.

čtyř os.
