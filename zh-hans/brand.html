品牌

先看肌肤。
COCODEMER 由此开始。

我们从一个简单的事实出发：
每个人的肌肤都不相同。

我们测量肌肤，读懂肌肤，再做出与之相符的产品。

为肌肤而设计

我们先读懂差异。

  • 干燥与油脂，
  • 敏感与耐受，
  • 色素的差异，
  • 皱纹与弹性。

肌肤因人而异，
同一个人的肌肤也会随时间变化。

COCODEMER 从未试图让一款产品
适合所有肌肤。

名称

源自海椰子（Coco de Mer）的名字

COCODEMER 这个名字来自
塞舌尔的海椰子（Coco de Mer）。

海椰子结出植物界最大的种子，
它不仅给了品牌名字，
也是我们早期原料研究的起点。

连接代码，
以接近内在价值

读懂让每种肌肤与众不同的特征，
找到与之相符的答案。

读懂每种肌肤的“code”，
发现其中原本就有的价值——
这一理念蕴含在品牌名称之中。

从定制到 SKIN CODE

我们先读懂肌肤，
再用不同的方式去做。

COCODEMER 最初是一项定制化妆品服务：
测量肌肤，根据差异进行调配，
一次服务一位顾客。

这些经验催生了17款成品，
可与调配产品一同在日常使用；

之后，通过 Skin Code Solution，
同样的肌肤解读延伸到了门店之外。

查看传承

留存下来的

方式停止了，
标准留了下来。

我们目前已不再提供
按顾客定制调配的服务。

在制作产品之前，我们依然
从肌肤及其所需出发。

现在

如今的 COCODEMER
将护肤设计为三个阶段。

先调理，

再补充所需，

让良好状态维持更久。

  1. 01

    RESET

    先调理肌肤

  2. 02

    BOOST

    补充肌肤所需

  3. 03

    KEEP

    让良好状态维持更久。

过去为每个人分别制作的产品，
如今按照肌肤状态所需的阶段来制作。

查看护肤体系

下一个 COCODEMER

产品更少，
值得信赖的理由更多。

COCODEMER 将继续打造
从肌肤状态与护理目的出发、
而非从产品出发的护肤品。

我们为每款产品积累所需的测试与数据，
一点一点增加依据。

原料传承

始于品牌名称的
原料研究

L-CODEMAR ELIXIR™ 的灵感源自海椰子种子，
是 COCODEMER 的独有原料，

开发于我们提供定制化妆品服务的时期。

它曾用于当时的成品系列，
其原料与配方记录至今仍有保存。

说明

目前在售的 Aqua Quick Bubble Mask
未使用 L-CODEMAR ELIXIR™。
