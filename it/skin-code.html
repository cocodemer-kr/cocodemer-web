SKIN CODE

Osservare prima la pelle,
anche fuori dal negozio.

In negozio, COCODEMER misurava la pelle
e preparava un prodotto per ogni cliente.

Non tutti, però,
potevano recarsi in negozio.

Per applicare lo stesso metodo di lettura
anche online,

abbiamo creato Skin Code Solution.

L'IDEA

Abbiamo prima distinto
le differenze.

Un solo criterio non bastava
per interpretare la pelle di una persona.

COCODEMER ha osservato la pelle
secondo quattro assi.

01DRY / OILYSecca / Grassa
02SENSITIVE / RESISTANTSensibile / Resistente
03PIGMENTED / NON-PIGMENTEDPigmentata / Non pigmentata
04WRINKLE / ELASTICITYRughe / Elasticità

I quattro assi si combinano in sedici tipi di pelle.

COCODEMER ha chiamato questa classificazione
COCODEMER Skin Type Indicator (CSTI).

16 TIPI DI PELLE

Sedici tipi,
ciascuno una combinazione diversa.

Sedici è il numero dei tipi di pelle,
non il numero dei prodotti.

Ogni tipo è una combinazione
dei quattro assi.

COME FUNZIONAVA

Si individuava il tipo,
poi si preparava il prodotto di conseguenza.

  1. 01ONLINE SKIN TESTCondizione della pelle verificata online
  2. 02SKIN TYPEIndividuazione di uno dei sedici tipi
  3. 03PRESCRIPTIONApplicazione della prescrizione per quel tipo
  4. 04INDIVIDUAL FORMULATIONSiero preparato per il cliente
  5. 05DELIVERYSpedizione del siero preparato

Skin Code non consisteva nello scegliere uno
tra una serie di prodotti già pronti.

Si individuava il tipo di pelle,
poi il siero veniva preparato
per il cliente secondo quella prescrizione.

98,319
PRESCRIZIONI POSSIBILI

Dietro Skin Code c'era
un sistema di preparazione su misura più ampio.

Il sistema di preparazione su misura in negozio consentiva
98.319 prescrizioni possibili.

Partendo da lì, Skin Code classificava la pelle
in sedici tipi e preparava un siero
secondo la prescrizione corrispondente
una volta che il test online aveva indicato un tipo.

BASE DI FORMULAZIONE

Anche all'interno di un solo tipo,
la preparazione non era identica.

Skin Code partiva da
quattro basi siero

in base al tipo di pelle e alla prescrizione.
