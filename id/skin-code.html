SKIN CODE

Melihat kulit terlebih dahulu,
juga di luar toko.

Di toko, COCODEMER mengukur kulit
dan meracik produk untuk setiap pelanggan.

Namun, tidak semua orang
dapat datang ke toko.

Untuk menerapkan cara membaca kulit yang sama
secara online juga,

kami membangun Skin Code Solution.

GAGASAN

Kami memilah perbedaannya
terlebih dahulu.

Satu kriteria saja tidak cukup
untuk membaca kulit satu orang.

COCODEMER melihat kulit
berdasarkan empat sumbu.

01DRY / OILYKering / Berminyak
02SENSITIVE / RESISTANTSensitif / Resisten
03PIGMENTED / NON-PIGMENTEDBerpigmen / Tidak berpigmen
04WRINKLE / ELASTICITYKerutan / Elastisitas

Keempat sumbu ini berpadu menjadi enam belas tipe kulit.

COCODEMER menamai klasifikasi ini
COCODEMER Skin Type Indicator (CSTI).

16 TIPE KULIT

Enam belas tipe,
masing-masing kombinasi yang berbeda.

Enam belas adalah jumlah tipe kulit,
bukan jumlah produk.

Setiap tipe merupakan kombinasi
dari keempat sumbu.

CARA KERJANYA

Tipenya ditentukan,
lalu diracik sesuai tipe itu.

  1. 01ONLINE SKIN TESTKondisi kulit diperiksa secara online
  2. 02SKIN TYPESalah satu dari enam belas tipe ditentukan
  3. 03PRESCRIPTIONResep untuk tipe tersebut diterapkan
  4. 04INDIVIDUAL FORMULATIONSerum diracik untuk pelanggan
  5. 05DELIVERYSerum racikan dikirim

Skin Code bukanlah soal memilih satu
dari sejumlah produk siap pakai.

Tipe kulit ditentukan,
lalu serum diracik
sesuai resep itu untuk pelanggan.

98,319
KEMUNGKINAN RESEP

Di balik Skin Code terdapat
sistem peracikan yang lebih besar.

Sistem peracikan di toko memungkinkan
98.319 kemungkinan resep.

Berangkat dari itu, Skin Code memilah kulit
menjadi enam belas tipe dan meracik serum
sesuai resep yang cocok
setelah tes online menentukan tipenya.
