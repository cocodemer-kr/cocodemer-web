SKIN CODE

店舗の外でも、
まず肌を見るために。

COCODEMERは店頭で肌を測定し、
お客様ごとに製品を調合していました。

しかし、誰もが
店舗に来られるわけではありませんでした。

同じ基準を
オンラインでも生かすために、

Skin Code Solutionをつくりました。

発想

まず、違いを
分けて考えました。

一人の肌を読み解くには、
ひとつの基準では足りませんでした。

COCODEMERは肌を
四つの軸で捉えました。

01DRY / OILY乾性 / 脂性
02SENSITIVE / RESISTANT敏感 / 抵抗性
03PIGMENTED / NON-PIGMENTED色素性 / 非色素性
04WRINKLE / ELASTICITYシワ / ハリ

四つの軸の組み合わせから、十六の肌タイプが生まれます。

COCODEMERはこの分類を
COCODEMER Skin Type Indicator（CSTI）と名づけました。

16の肌タイプ

十六のタイプ、
それぞれ異なる組み合わせ。

十六は肌タイプの数であり、
製品の数ではありません。

それぞれのタイプは、
四つの軸の組み合わせです。

当時の仕組み

タイプを判定し、
それに合わせて調合しました。

  1. 01ONLINE SKIN TESTオンラインで肌の状態を確認
  2. 02SKIN TYPE十六タイプのうちひとつを判定
  3. 03PRESCRIPTIONそのタイプの処方を適用
  4. 04INDIVIDUAL FORMULATIONお客様ごとにセラムを調合
  5. 05DELIVERY調合したセラムを発送

Skin Codeは、あらかじめつくられた製品の中から
ひとつを選ぶものではありませんでした。

肌タイプを判定したうえで、
その処方に沿って
お客様ごとにセラムを調合しました。

98,319
可能な処方

Skin Codeの背景には、
より大きな調合システムがありました。

店頭のオーダーメイド調合システムでは、
98,319通りの処方が可能でした。

それをもとに、Skin Codeは肌を
十六のタイプに分け、オンラインテストで
タイプが判定されると、対応する処方に沿って
セラムを調合しました。

処方ベース

Skin Codeでは
四種のセラムベースをもとに、

アクティブの構成を変えていました。
