品牌

先看肌膚。
COCODEMER 從這裡出發。

我們從一個單純的事實出發：
每個人的肌膚都不同。

我們測量，解讀，再做出相符的產品。

為肌膚而設計

我們先解讀差異。

  • 乾燥與油脂，
  • 敏感與耐受，
  • 色素的差異，
  • 皺紋與彈性。

每個人的肌膚都不同，
同一個人的肌膚也會隨時間改變。

COCODEMER 並不打算讓一款產品
適用於所有肌膚。

名字

源自 coco de mer 的名字

COCODEMER 這個名字，
來自塞席爾的海椰子（coco de mer）。

這種樹結出植物界最大的種子，
它不僅給了品牌名字，
也是我們早期原料研究的起點。

以代碼，
接近本質的優點

解讀讓每種肌膚各不相同的特質，
找出適合它的答案。

解讀每種肌膚的「code」，
找出其中原本就有的價值——
這個想法就藏在名字裡。

從客製化到 Skin Code

我們解讀肌膚，
再做出不同的產品。

COCODEMER 最初是一項客製化妝品服務：
測量肌膚，依照差異調配，
一次服務一位顧客。

這些經驗延伸出 17 款成品，
與調配產品一同在日常中使用，

之後透過 Skin Code Solution，
將同樣的解讀方式延續到門市之外。
