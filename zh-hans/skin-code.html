SKIN CODE

在门店之外，
同样先读懂肌肤。

在门店，COCODEMER 测量肌肤，
并为每位顾客调配产品。

然而，并非每个人
都能到店。

为了在线上
也运用同样的肌肤解读，

我们打造了 Skin Code Solution。

理念

我们先把差异
区分开来。

仅凭一项标准，
不足以读懂一个人的肌肤。

COCODEMER 从
四个维度观察肌肤。

01DRY / OILY干性 / 油性
02SENSITIVE / RESISTANT敏感 / 耐受
03PIGMENTED / NON-PIGMENTED色素型 / 非色素型
04WRINKLE / ELASTICITY皱纹 / 弹性

四个维度组合成十六种肤质类型。

COCODEMER 将这一分类体系命名为
COCODEMER Skin Type Indicator（CSTI）。

16种肤质类型

十六种类型，
各是一种不同的组合。

十六是肤质类型的数量，
而非产品的数量。

每种类型都是
四个维度的组合。

当时的运作方式

先确定类型，
再据此调配。

  1. 01ONLINE SKIN TEST线上检测肌肤状态
  2. 02SKIN TYPE确定为十六种类型之一
  3. 03PRESCRIPTION应用该类型的配方
  4. 04INDIVIDUAL FORMULATION为顾客调配精华液
  5. 05DELIVERY寄送调配好的精华液

Skin Code 并不是从一组现成产品中
挑选一款。

先确定肤质类型，
再按照相应配方
为顾客调配精华液。

98,319
可实现的配方

在 Skin Code 背后，
是一套更大的调配体系。

门店的定制调配体系
可实现98,319种配方。

在此基础上，Skin Code 将肌肤
分为十六种类型，线上测试得出类型后，
按照对应的配方
调配精华液。

配方基底

即使在同一类型之内，
调配也不尽相同。

Skin Code 以
四种精华基底为基础，

并根据肤质类型与配方
调整活性成分。
