01 · 定制

一切始于
一个人的肌肤。

档案

我们没有先挑选产品。

门店的肌肤分析仪拍摄面部后给出
两百多项数据——额头的泛红、鼻部的油脂、
眼下的色素等。

读懂当天的肌肤后，
我们为这位顾客调配精华液和面霜。

调配时，精华液依据四项标准、
面霜依据三项标准，
并随肌肤状态而调整。

产品本身
因顾客而异。

一个月后顾客再次到店时，
我们会重新测量肌肤。

如果肌肤发生了变化，
我们不会重复之前的配方。

我们会针对眼前的肌肤
重新调配。

说明

精华液四项、面霜三项指的是调配标准，并非产品数量。
按顾客定制调配的服务现已不再提供。

03 · SKIN CODE

同样的肌肤解读，
延伸到门店之外。

为了让无法到店的人
也能以同样的方式读懂自己的肌肤，

我们打造了 Skin Code Solution。

  • 干性 / 油性
  • 敏感 / 耐受
  • 色素型 / 非色素型
