SKIN CODE

Membaca kulit terlebih dahulu,
di luar kedai juga.

Di kedai, COCODEMER mengukur kulit
dan mengadun produk untuk setiap pelanggan.

Namun, tidak semua orang
dapat mengunjungi kedai.

Untuk menerapkan cara membaca yang sama
secara dalam talian juga,

kami membina Skin Code Solution.

GAGASAN

Kami mengasingkan perbezaannya
terlebih dahulu.

Satu kriteria tidak mencukupi
untuk membaca kulit seseorang.

COCODEMER melihat kulit
berdasarkan empat paksi.

02SENSITIVE / RESISTANTSensitif / Tahan
03PIGMENTED / NON-PIGMENTEDBerpigmen / Tidak berpigmen

Empat paksi ini bergabung menjadi enam belas jenis kulit.

COCODEMER menamakan klasifikasi ini
COCODEMER Skin Type Indicator (CSTI).

16 JENIS KULIT

setiap satunya gabungan yang berbeza.

Enam belas ialah bilangan jenis kulit,
bukan bilangan produk.

Setiap jenis ialah gabungan
empat paksi tersebut.

CARA IA BERFUNGSI

Jenisnya dikenal pasti,
kemudian diadun mengikutnya.

  1. 01ONLINE SKIN TESTKeadaan kulit diperiksa secara dalam talian
  2. 02SKIN TYPESalah satu daripada enam belas jenis dikenal pasti
  3. 03PRESCRIPTIONPreskripsi bagi jenis tersebut diterapkan
  4. 04INDIVIDUAL FORMULATIONSerum diadun untuk pelanggan
  5. 05DELIVERYSerum yang telah diadun dihantar

Skin Code bukanlah soal memilih satu
daripada set produk sedia ada.

Jenis kulit dikenal pasti,
kemudian serum diadun
mengikut preskripsi tersebut untuk pelanggan.

98,319
PRESKRIPSI YANG MUNGKIN

Di sebalik Skin Code terdapat
sistem adunan khas yang lebih besar.

Sistem adunan khas di kedai membolehkan
98,319 preskripsi yang mungkin.

Berasaskan sistem itu, Skin Code mengasingkan kulit
kepada enam belas jenis dan mengadun serum
mengikut preskripsi yang sepadan
sebaik sahaja ujian dalam talian menentukan jenisnya.
