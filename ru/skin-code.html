SKIN CODE

Сначала изучать кожу —
и за пределами магазина.

В магазине COCODEMER измерял кожу
и составлял средство для каждого клиента.

Однако не каждый
мог прийти в магазин.

Чтобы применять тот же подход
и онлайн,

мы создали Skin Code Solution.

ИДЕЯ

Сначала мы разделили
различия.

Одного критерия было недостаточно,
чтобы понять кожу одного человека.

COCODEMER рассматривал кожу
по четырём осям.

01DRY / OILYСухая / Жирная
02SENSITIVE / RESISTANTЧувствительная / Устойчивая
03PIGMENTED / NON-PIGMENTEDПигментированная / Непигментированная
04WRINKLE / ELASTICITYМорщины / Упругость

Четыре оси в сочетании дают шестнадцать типов кожи.

COCODEMER назвал эту классификацию
COCODEMER Skin Type Indicator (CSTI).

16 ТИПОВ КОЖИ

Шестнадцать типов —
шестнадцать разных сочетаний.

Шестнадцать — это количество типов кожи,
а не количество продуктов.

Каждый тип — это сочетание
четырёх осей.

КАК ЭТО РАБОТАЛО

Сначала определялся тип,
затем под него составлялось средство.

  1. 01ONLINE SKIN TESTОнлайн-оценка состояния кожи
  2. 02SKIN TYPEОпределение одного из шестнадцати типов
  3. 03PRESCRIPTIONПрименение рецептуры для этого типа
  4. 04INDIVIDUAL FORMULATIONСоставление сыворотки для клиента
  5. 05DELIVERYОтправка составленной сыворотки

Skin Code не сводился к выбору одного
из набора готовых продуктов.

Определялся тип кожи,
а затем по этой рецептуре
для клиента составлялась сыворотка.

98,319
ВОЗМОЖНЫЕ РЕЦЕПТУРЫ

За Skin Code стояла
более масштабная система индивидуального составления.

Система индивидуального составления в магазине позволяла
создать 98 319 возможных рецептур.

Опираясь на неё, Skin Code распределял кожу
по шестнадцати типам и, когда онлайн-тест определял тип,
составлял сыворотку
по соответствующей рецептуре.
